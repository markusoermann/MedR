# MedR_git: Materialien zum Urheber- und Medienrecht

Herzlich willkommen im Repository für das Modul **Urheber- und Medienrecht (BDGD 4)** im Studiengang Digitale Gesellschaft (Bachelor of Science) an der Technischen Hochschule Würzburg-Schweinfurt (THWS). Alle Infos zum Studiengang finden sich unter: https://fiw.thws.de/studium/bachelor-digitale-gesellschaft-bdgd/. 

Dieses Projekt nutzt einen modernen **Single-Source-Publishing-Ansatz** auf Basis von **Quarto**. Aus den hier vorliegenden Markdown-Quelldateien (`.qmd`) werden sowohl interaktive Lernmodule für Moodle als auch statische PDF-Skripte generiert.

## 🎓 Struktur der Lerneinheiten

Das Repository ist in chronologische Einheiten gegliedert, die den Semesterverlauf abbilden.

## 🛠 Interaktive Elemente (Widgets)

Ein besonderes Merkmal dieses Kurses sind die **interaktiven HTML-Widgets**, die direkt in die Skripte eingebettet sind. Sie dienen dazu, komplexe juristische Abwägungen und technische Abläufe spielerisch zu erkunden.

Die Widgets befinden sich im Verzeichnis `/widgets`.
